## 1. Mathematical results and Lean translation

**Design goal.** The [source header](https://github.com/leanprover-community/mathlib4/blob/7d32461ad224e921eb05ead7ac02156702f4aa59/Mathlib/Probability/UniformOn.lean#L13-L38) motivates a measure-theoretic formulation of classical finite counting probability for combinatorics. ### 1.1 Main construction: conditioning counting measure

Let $(\Omega,\mathcal A)$ be a measurable space, let $S\subseteq\Omega$, and write $\nu=\mathrm{count}$ for counting measure. The central definition is the measure obtained by conditioning $\nu$ on $S$:

$$
P_S(A)=\nu[A\mid S]=\nu(S)^{-1}\nu(S\cap A).
$$

Whenever $S$ is **finite, nonempty, and measurable**, and the relevant intersection is measurable (for instance, when $A$ is measurable), this is the familiar discrete uniform probability

$$
P_S(A)=\frac{|S\cap A|}{|S|}.
$$

Kallenberg (2021, Chapter 1, p. 19) constructs counting measure as a sum of unit point masses, and Exercise 1.3 (p. 31) asks for its cardinality-based definition on an arbitrary power-set measurable space. Normalization on a finite nonempty support gives the displayed ratio. For an explicit elementary definition of a finite uniform distribution, see also Grinstead and Snell (2006, §1.2, Definition 1.3).

The formula defining `uniformOn` exists without finite/nonempty hypotheses; in degenerate cases it need not be a probability measure. The values live in `ℝ≥0∞` (`ENNReal`) when a measure is evaluated on an event.

**Exact source definition:**

```lean
namespace ProbabilityTheory

variable {Ω : Type*} [MeasurableSpace Ω] {s : Set Ω}

def uniformOn (s : Set Ω) : Measure Ω :=
  Measure.count[|s]
deriving IsZeroOrProbabilityMeasure
```

`Measure.count[|s]` is the library's conditional/restricted-and-normalized measure notation, not an ordinary restriction of counting measure. The `deriving` declaration supplies an `IsZeroOrProbabilityMeasure` instance: this construction may be a zero measure rather than a probability measure. The **generated declaration** is `ProbabilityTheory.instIsZeroOrProbabilityMeasureUniformOn`, with type `IsZeroOrProbabilityMeasure (uniformOn s)` (under `[MeasurableSpace Ω]`). Thus, in addition to **26 declarations written by name** in the source, one public instance is generated by `deriving`. `noncomputable section` also appears in the source; the definition is meant as a measure-theoretic object, not an executable sampler.

The fixed revision has three direct public imports, providing conditional probability, counting measure, and product measures:

### 1.2 Probability-measure validity

**Theorem.** A finite, nonempty measurable set has positive and finite counting measure, so conditioning counting measure on it yields a probability measure:

$$
S\text{ finite and nonempty}\quad\Longrightarrow\quad P_S(\Omega)=1.
$$

The file exposes a theorem with an **explicit measurability** hypothesis and one using the stronger ambient `MeasurableSingletonClass Ω` instance. This uses the standard normalization of a probability measure, described in Kallenberg (2021, Chapter 4, pp. 81–82).

**Exact source declarations and proof:**

```lean
theorem isProbabilityMeasure_uniformOn' {s : Set Ω}
    (hs_fin : s.Finite) (hs_nonempty : s.Nonempty) (hs_meas : MeasurableSet s) :
    IsProbabilityMeasure (uniformOn s) := by
  apply cond_isProbabilityMeasure_of_finite
  · rwa [Measure.count_ne_zero_iff]
  · exact (Measure.count_apply_lt_top' hs_meas).2 hs_fin |>.ne

-- The following theorem occurs after:
-- variable [MeasurableSingletonClass Ω]
theorem isProbabilityMeasure_uniformOn {s : Set Ω}
    (hs : s.Finite) (hs' : s.Nonempty) :
    IsProbabilityMeasure (uniformOn s) := by
  apply cond_isProbabilityMeasure_of_finite
  · rwa [Measure.count_ne_zero_iff]
  · exact (Measure.count_apply_lt_top.2 hs).ne
```

**Mathematical proof.** The imported result `cond_isProbabilityMeasure_of_finite` reduces probability-measure validity of `ν[|S]` to `ν(S) ≠ 0` and `ν(S) ≠ ∞`. For counting measure:

- `S.Nonempty` gives `Measure.count S ≠ 0` using `Measure.count_ne_zero_iff`;
- `S.Finite` gives `Measure.count S < ∞`; the explicit-measurability version also passes `MeasurableSet S` to `Measure.count_apply_lt_top'`;
- with `MeasurableSingletonClass Ω`, finite sets are measurable and `Measure.count_apply_lt_top` can be applied directly.

The `apply` tactic creates the nonzero and finite-mass subgoals; `rwa` rewrites the former into nonemptiness; `exact ... .ne` discharges the latter by turning `< ∞` into `≠ ∞`.

**Initial proof goal**, recorded by `trace_state` at the pinned revision:

```text

inst✝¹ : MeasurableSpace.{u_1} Ω
inst✝ : MeasurableSingletonClass.{u_1} Ω

hs' : Set.Nonempty.{u_1} s
⊢ IsProbabilityMeasure.{u_1} (uniformOn.{u_1} s)
```

The file also declares a **distinct**, non-derived probability-measure instance for the universe of a finite nonempty type:


### 1.3 Finite counting formula

**Theorem.** For finite sets $S,T$, provided their coercions to `Set Ω` are measurable,

$$
P_S(T)=\frac{|S\cap T|}{|S|}.
$$

This is an equality of `ENNReal` values, including the empty-$S$ case (where the library's zero-division conventions apply).

**Exact source declarations:**

```lean
lemma uniformOn_apply_finset' {Ω : Type*} [DecidableEq Ω]
    {_ : MeasurableSpace Ω} {s t : Finset Ω}
    (hs : MeasurableSet (s : Set Ω))
    (ht : MeasurableSet (t : Set Ω)) :
    uniformOn (s : Set Ω) (t : Set Ω) = #(s ∩ t) / #s := by
  rw [uniformOn, cond_apply hs, Measure.count_apply_finset' hs, ← coe_inter,
    Measure.count_apply_finset']
  · rw [div_eq_mul_inv, mul_comm]
  rw [coe_inter]
  exact hs.inter ht

-- After variable [MeasurableSingletonClass Ω]:
lemma uniformOn_apply_finset [DecidableEq Ω] {s t : Finset Ω} :
    uniformOn (s : Set Ω) (t : Set Ω) = #(s ∩ t) / #s :=
  uniformOn_apply_finset' s.measurableSet t.measurableSet
```

**Proof design.** `cond_apply hs` expands the conditional measure to the inverse total mass times the intersection mass. `Measure.count_apply_finset'` replaces counting-measure values by finite-set cardinalities. `coe_inter` reconciles `Finset` intersection with `Set` intersection. `div_eq_mul_inv` and `mul_comm` normalize the arithmetic expression. The final measurability goal follows from `hs.inter ht`.

`[DecidableEq Ω]` is an effective equality-decision requirement for `Finset` operations, **not** a probability-theoretic independence assumption. The unprimed theorem avoids explicit `MeasurableSet` arguments because `MeasurableSingletonClass Ω` makes finite sets measurable.

### 1.4 Zero and one events: support-sensitive characterizations

Under `s.Finite`, the file proves

```lean
theorem uniformOn_eq_zero_iff (hs : s.Finite) :
    uniformOn s t = 0 ↔ s ∩ t = ∅ := by
  simp [uniformOn, cond_apply hs.measurableSet, Measure.count_apply_eq_top,
    Set.not_infinite.2 hs,
    Measure.count_apply_finite _ (hs.inter_of_left _)]
```

Thus a finite uniform model gives a zero value to an event exactly when the event contains **no** possible outcome. This remains valid when `s = ∅`, although that case gives a zero measure rather than a probability measure.

In the nonempty finite case, an event containing every point of `s` has measure one. More surprisingly, measure one also forces it to contain **every** point of `s`. The exact source names are:

```lean
theorem uniformOn_eq_one_of
    (hs : s.Finite) (hs' : s.Nonempty) (ht : s ⊆ t) :
    uniformOn s t = 1 := by
  have := isProbabilityMeasure_uniformOn hs hs'
  refine eq_of_le_of_not_lt prob_le_one ?_
  rw [not_lt, ← uniformOn_self hs hs']
  exact measure_mono ht

theorem pred_true_of_uniformOn_eq_one (h : uniformOn s t = 1) :
    s ⊆ t := by
  have hsf := finite_of_uniformOn_ne_zero (by rw [h]; exact one_ne_zero)
  rw [uniformOn, cond_apply hsf.measurableSet, mul_comm] at h
  replace h := ENNReal.eq_inv_of_mul_eq_one_left h
  rw [inv_inv, Measure.count_apply_finite _ hsf,
    Measure.count_apply_finite _ (hsf.inter_of_left _), Nat.cast_inj] at h
  suffices s ∩ t = s by exact this ▸ fun x hx => hx.2
  rw [← @Set.Finite.toFinset_inj _ _ _ (hsf.inter_of_left _) hsf]
  exact Finset.eq_of_subset_of_card_le
    (Set.Finite.toFinset_mono s.inter_subset_left) h.ge
```

The backward theorem has **no explicit `s.Finite` hypothesis**: it first derives finiteness from `uniformOn s t ≠ 0`. Then, probability one implies equal counting masses, and a finite subset of the same cardinality must equal the original finite set. This is stronger than general almost-sure reasoning on non-atomic spaces. The ambient singleton-measurability instance is still inherited.

### 1.5 Multiplication formula (`uniformOn_inter`)

**Theorem.** For finite $S$ and events $T,U$,

$$
P_S(T\cap U)=P_{S\cap T}(U)\,P_S(T).
$$

**Exact source statement:**

```lean
theorem uniformOn_inter (hs : s.Finite) :
    uniformOn s (t ∩ u) = uniformOn (s ∩ t) u * uniformOn s t := by
  by_cases hst : s ∩ t = ∅
  · rw [hst, uniformOn_empty_meas, Measure.coe_zero, Pi.zero_apply, zero_mul,
      uniformOn_eq_zero_iff hs, ← Set.inter_assoc, hst, Set.empty_inter]
  rw [uniformOn, uniformOn, cond_apply hs.measurableSet, cond_apply hs.measurableSet,
    cond_apply (hs.inter_of_left _).measurableSet, mul_comm _ (Measure.count (s ∩ t)),
    ← mul_assoc, mul_comm _ (Measure.count (s ∩ t)), ← mul_assoc,
    ENNReal.mul_inv_cancel, one_mul, mul_comm, Set.inter_assoc]
  · rwa [← Measure.count_eq_zero_iff] at hst
  · exact (Measure.count_apply_lt_top.2 <| hs.inter_of_left _).ne
```

**Proof.** `by_cases hst : s ∩ t = ∅` separates the zero-condition case from the case where the conditioning set is nonempty. In the empty branch, both sides are zero. Otherwise the author expands the conditional counting measure, rearranges the product, and cancels the finite positive mass `count (s ∩ t)` via `ENNReal.mul_inv_cancel`. The two trailing goals certify that mass is neither zero nor infinity. Finiteness is the explicit theorem hypothesis; nonemptiness of `s ∩ t` is **not** an additional global hypothesis.

When $P_S(T)>0$, the factor $P_{S\cap T}(U)$ is the usual conditional probability $P_S(U\mid T)$. Kallenberg (2021, Chapter 8, Theorem 8.1(i), pp. 164–165, and the definition of conditional probability on p. 167) supplies the general conditional-expectation framework, with conditioning on the σ-field $\sigma(T)$ generated by the event $T$. When $P_S(T)=0$, `uniformOn_eq_zero_iff` gives $S\cap T=\varnothing$, so `uniformOn ∅` is the zero measure and the identity still holds. This zero-mass branch uses Mathlib's zero-measure convention; it does not follow from the usual conditional-probability ratio, whose denominator would vanish. Conditional expectations in the general measure-theoretic formulation are determined only up to almost-sure equality (Kallenberg, 2021, Chapter 8, p. 163), so they do not specify conditional values on a null event.

### 1.6 Weighted disjoint-union identity and total probability

Let finite $S_1,S_2$ be disjoint and let $S=S_1\cup S_2$. For an event $A$,

$$
P_S(A)=P_{S_1}(A)P_S(S_1)+P_{S_2}(A)P_S(S_2).
$$

The file states this with **both** subsets finite and disjoint; it does not require them to be nonempty:

```lean
theorem uniformOn_disjoint_union
    (hs : s.Finite) (ht : t.Finite) (hst : Disjoint s t) :
    uniformOn s u * uniformOn (s ∪ t) s +
      uniformOn t u * uniformOn (s ∪ t) t =
      uniformOn (s ∪ t) u := by
  rcases s.eq_empty_or_nonempty with (rfl | hs') <;>
    rcases t.eq_empty_or_nonempty with (rfl | ht')
  · simp
  · simp [uniformOn_self ht ht']
  · simp [uniformOn_self hs hs']
  rw [uniformOn, uniformOn, uniformOn, cond_apply hs.measurableSet,
    cond_apply ht.measurableSet, cond_apply (hs.union ht).measurableSet,
    cond_apply (hs.union ht).measurableSet,
    cond_apply (hs.union ht).measurableSet]
  conv_lhs =>
    rw [Set.union_inter_cancel_left, Set.union_inter_cancel_right,
      mul_comm (Measure.count (s ∪ t))⁻¹,
      mul_comm (Measure.count (s ∪ t))⁻¹, ← mul_assoc,
      ← mul_assoc, mul_comm _ (Measure.count s),
      mul_comm _ (Measure.count t), ← mul_assoc, ← mul_assoc]
  rw [ENNReal.mul_inv_cancel, ENNReal.mul_inv_cancel,
    one_mul, one_mul, ← add_mul, ← measure_union,
    Set.union_inter_distrib_right, mul_comm]
  exacts [hst.mono inf_le_left inf_le_left,
    (ht.inter_of_left _).measurableSet,
    Measure.count_ne_zero ht', (Measure.count_apply_lt_top.2 ht).ne,
    Measure.count_ne_zero hs', (Measure.count_apply_lt_top.2 hs).ne]
```

**Proof architecture.** `rcases` dispatches four empty/nonempty possibilities. In the both-nonempty branch, `conv_lhs` performs localized rewriting; `ENNReal.mul_inv_cancel` cancels the subpopulation masses, and `measure_union` uses disjointness. The final proof obligations justify disjointness, measurability, nonzero masses, and finite masses.

Taking the partition $S=(S\cap U)\cup(S\cap U^c)$ gives a finite counting version of the **law of total probability**:

$$
P_S(T)=P_{S\cap U}(T)P_S(U)+P_{S\cap U^c}(T)P_S(U^c).
$$

The averaging and tower properties of conditional expectation (Kallenberg, 2021, Theorem 8.1(i), (vii), pp. 164–165) yield the familiar total-probability formula by applying them to the indicator of $T$ and the σ-field generated by $U$. The finite counting identity above also covers empty components through zero-weight terms.

**Exact source theorem and proof:**

```lean
theorem uniformOn_add_compl_eq (u t : Set Ω) (hs : s.Finite) :
    uniformOn (s ∩ u) t * uniformOn s u +
      uniformOn (s ∩ uᶜ) t * uniformOn s uᶜ =
      uniformOn s t := by
  conv_rhs =>
    rw [(by simp : s = s ∩ u ∪ s ∩ uᶜ),
      ← uniformOn_disjoint_union (hs.inter_of_left _)
        (hs.inter_of_left _)
        (disjoint_compl_right.mono inf_le_right inf_le_right)]
  simp [uniformOn_inter_self hs]
```

This proof is almost entirely **theorem reuse**: partition the support, apply the disjoint-union theorem backward, and simplify with `uniformOn_inter_self`. Nonemptiness is not required because a zero-weight component is handled by the zero measure convention.

### 1.7 Finite product uniform measure (`uniformOn_pi`)

Given a finite coordinate index type `ι` and coordinate sets $S_i$, the complete product set $\prod_i S_i$ carries the product of its coordinatewise uniform measures:

$$
P_{\prod_i S_i}=\bigotimes_{i\in\iota}P_{S_i}.
$$

**Exact source statement and proof:**

```lean
-- File-level context: [MeasurableSingletonClass Ω]
variable {ι : Type*} [Fintype ι]

lemma uniformOn_pi [Finite Ω] {f : ι → Set Ω} :
    uniformOn (Set.univ.pi f) = Measure.pi fun i ↦ uniformOn (f i) := by
  refine (MeasureTheory.Measure.pi_eq fun t ht ↦ ?_).symm
  lift f to ι → Finset Ω using by simp [Set.toFinite]
  lift t to ι → Finset Ω using by simp [Set.toFinite]
  classical
  simp [← Fintype.coe_piFinset, uniformOn_apply_finset,
    ← Fintype.piFinset_inter, ENNReal.prod_div_distrib_of_ne_top]
```

**Mathematical proof.** A product-measure uniqueness theorem (`Measure.pi_eq`) reduces equality of measures to equality on measurable rectangles. Since `Ω` is finite and `ι` is a finite index type, the coordinate sets and rectangle factors can be represented as `Finset`s. Note the distinction between `[Finite Ω]` and `[Fintype ι]`: the former allows noncomputable finiteness, while the latter supplies an explicit finite index enumeration. The imported `MeasureTheory.Measure.pi_eq` additionally requires that each factor measure be `SigmaFinite`; this requirement is discharged by the existing measure instances, rather than appearing as an extra user-facing assumption in `uniformOn_pi`. Their intersection and product cardinalities factor coordinatewise:

$$
\frac{|(\prod_i S_i)\cap(\prod_i T_i)|}{|\prod_i S_i|}
=\frac{\prod_i|S_i\cap T_i|}{\prod_i|S_i|}
=\prod_i\frac{|S_i\cap T_i|}{|S_i|}.
$$

The final `simp` invokes the finite-set product, intersection, and `ENNReal` product-of-quotients APIs. The equality is of **measures** and does not require `Nonempty (f i)`: an empty coordinate support gives the zero measure. Nonempty supports are needed to interpret each factor as a probability distribution. Kallenberg (2021, Theorem 1.29(i), p. 25) characterizes product measures by their values on measurable rectangles, while Lemma 4.10 (pp. 88–89) relates product laws to independence. The finite-uniform identity follows by combining this framework with the cardinality factorization above.

## 4. Boundary conditions and scope

**(a) Empty and infinite support.** With measurable support (or ambient singleton measurability), the exact statement is:

```lean
@[simp] lemma uniformOn_eq_zero [MeasurableSingletonClass Ω] :
    uniformOn s = 0 ↔ s.Infinite ∨ s = ∅ := by
  simp [uniformOn]
```

Thus the construction is **not** an infinite-set uniform probability distribution. If `s` is infinite, conditional counting measure yields the zero measure. This says nothing against constructing other probability distributions on infinite spaces by different means.

**(b) Zero measure versus zero event.** `uniformOn_eq_zero` compares an entire `Measure Ω` with zero. `uniformOn_eq_zero_iff` instead compares the `ENNReal` mass of a particular event with zero; the finite-support hypothesis is essential to its stated equivalence.

**(c) One event versus almost surely.** For the finite uniform model, `P_s(t) = 1` entails literal `s ⊆ t`, not just an almost-sure statement modulo a null set. The proof uses positivity of individual support-point masses through the finite counting argument.

**(d) Partial / zero-probability conditioning.** `uniformOn_inter` and `uniformOn_add_compl_eq` are valid as measure identities in empty-set cases, without interpreting `uniformOn ∅` as an ordinary conditional **probability** distribution.

**(e) Complete product versus constrained support.** `uniformOn_pi` concerns `Set.univ.pi f`, the **full** product of coordinate supports. It does not assert independent coordinates for an arbitrary subset of that product. Its mathematical content is measure equality, with the probability-distribution interpretation requiring nonempty coordinate supports.

**(f) Declaration name in the source comment.** The header mentions `ProbabilityTheory.uniformOn_isProbabilityMeasure`, but the theorem provided by this revision is `ProbabilityTheory.isProbabilityMeasure_uniformOn`.
